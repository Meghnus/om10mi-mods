These pictures are not covered by the licences that apply to the code and the data in this repository.

What they show: scenes shot on an OM-D E-M10 Mark I as RAW, then converted in the camera (RAW Data Edit) with
firmware version 56. Straight out of camera, no editing.

- `<scene>_natural.jpg` (alley: `alley_i-enhance.jpg`): the stock rendering of the same RAW, from the preview
  JPEG the camera stores inside the RAW file. The alley scene was shot in i-Enhance, the others in Natural.
- `<scene>_eterna.jpg`, `_nostalgic-neg.jpg`, `_ektar-100.jpg`, `_classic-neg.jpg`: the same RAW converted with
  that look.
- `<scene>_sheet.jpg`: all five side by side, labelled.

All metadata has been removed, and every picture is resized to 1600 px on the long side.
