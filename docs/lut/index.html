LUT → E-M10 Mk I camera look om10mi-lut, model cm-v2-web1

Everything runs in this page. Your LUT and photos are read from disk into memory and never uploaded (CSP: no external connections). The model holds only our own measured per-mode parameters. Scores are model predictions, not camera results.

New: look list manager (reorder and rename the Picture Mode list, replace several looks, export a pack file for looktool/om10mi_look.py --pack). This page stays the single-LUT workbench.

Disclaimer. Unofficial, for the Olympus OM-D E-M10 Mark I (model 0x1130, firmware 1.4) only. This page never talks to a camera and does not contain, produce or distribute any firmware. It writes a small look file (our own fitted numbers). Turning that file into a firmware image is done on your own PC with your own copy of the official firmware (om10mi-mods); flashing a modified image is at your own risk, can make the camera unusable and voids support. Scores are model predictions, not camera results. No affiliation with or endorsement by OM Digital Solutions / Olympus.
